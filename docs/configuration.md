# 設定（コマンドライン引数と設定ファイル）

ntpterminal のオプションは、コマンドライン引数と TOML 形式の設定ファイルのどちらでも指定できる。
同じ項目を複数の場所で指定した場合は、**コマンドライン、設定ファイル、既定値** の順に優先される。

## コマンドライン引数の書き方

```text
ntpterminal [--config <PATH>] <コマンド> [オプション...] [サーバ]
```

```sh
ntpterminal tui 192.168.1.123
ntpterminal tui 192.168.1.123 --interval-ms 200 --trend --title "GNSS TIME SERVER"
ntpterminal stats --count 0 --json 127.0.0.1:12300
ntpterminal once --transport raw-ip --dscp 46 192.168.1.123
ntpterminal tui --ptp4l
ntpterminal sim-server --offset-ms -0.978 --refid GNSS
```

- コマンドは `tui`・`once`・`stats`・`sim-server` のいずれか（内容は [usage.md](usage.md) を参照）
- オプションはコマンド名の後に書く。コマンド名の前に書けるのは `--config` だけである
  （`ntpterminal --interval-ms 200 tui` はエラーになる）
- 値を取るオプションは `--interval-ms 200` と `--interval-ms=200` のどちらの形でも書ける
- 問い合わせるサーバは、オプションの前後どちらに書いてもよい（`tui`・`once`・`stats` のみ）。
  設定ファイルに `server` を書いてあれば省略できる。`--ptp4l` のときはサーバを指定しない
- `--trend`・`--json`・`--no-df`・`--ptp4l`・`--allow-fast-poll` は値を取らないフラグで、付けると有効になる
  （`--trend=true` のように値を付けるとエラーになる）
- 負の値はそのまま書ける（`--offset-ms -0.978`、`--tz -05:00`）
- 空白を含む値は、シェルの引用符で囲む（`--footer "Sponsored by ..."`）
- 短い形式のオプションは `-h`（ヘルプ）と、コマンド名の前に書く `-V`（バージョン）だけである
- 未知のオプションや範囲外の値は、実行前にエラーとする。送信方式と組み合わせられないオプション
  （`udp` での `--dscp` など）も、無視せずにエラーとする
- 各コマンドのオプションの一覧は `ntpterminal <コマンド> --help` で確認できる

## 設定ファイルの場所

| 指定方法                                            | 読み込むファイル                                                                 |
|-----------------------------------------------------|----------------------------------------------------------------------------------|
| `--config <PATH>`                                   | 指定したファイル。存在しなければエラーになる                                     |
| 指定なし                                            | カレントディレクトリの `config.toml`。存在しなければ設定ファイルなしで動作する（存在するのに読めない場合はエラー） |
| `--config /dev/null`（Windows では `--config NUL`） | 何も読み込まない。スクリプトから実行するときなど、手元の設定を反映させたくない場合に使う |

`--config` はコマンド名の前後どちらに書いてもよい（`ntpterminal --config booth.toml tui` と
`ntpterminal tui --config booth.toml` は同じ意味になる）。
なお、リポジトリ直下の `config.toml` は `.gitignore` で除外されている。

## 設定ファイルの書き方

全項目を記載したひな形は [config.example.toml](config.example.toml) にある（使う行のコメントを外して使う）。

```toml
# tui / once / stats に共通する項目は、最初のセクションより前に書く
server = "192.168.1.123"

[tui]
interval-ms = 200
title = "GNSS TIME SERVER"
trend = true
```

- キーにはコマンドラインの長いオプション名から `--` を除いたものを使い、値も同じ形式で書く
  （`--interval-ms 200` なら `interval-ms = 200`）。数値はそのまま書き、アドレス・タイムゾーン・選択肢などは
  文字列として書く。コマンドラインでフラグのもの（`--trend` など）は `true` / `false` で書く
- 共通の項目はファイルの先頭（セクションの外）に書き、特定のコマンドだけで使う項目は
  `[tui]`・`[once]`・`[stats]`・`[sim-server]` の各セクションに書く。TOML ではセクションの後に書いたキーは
  そのセクションに属するため、たとえば `[tui]` の後に `server` を書くとエラーになる
- フラグの項目（`trend`、`json`、`no-df`、`ptp4l`）は、設定ファイルで `true` にするとコマンドラインから `false` に戻せない。
  コマンドラインには、これらを有効にするオプションしかないためである
- 未知のキー（綴りの誤りを含む）や、値の型・範囲・形式の誤りは、行と列を示したうえで起動時にエラーとする
- 項目どうしの組み合わせ（`udp` での `dscp` や、`snmp-community` なしの `snmp-port` など）は、コマンドラインの値と
  合わせた後で検査する。たとえば設定ファイルに `transport = "raw-ip"` と `dscp` を書き、コマンドラインで
  `--transport udp` を指定するとエラーになる
- `snmp-community` を書いたファイルは、他のユーザーから読めないようにしておくこと（Linux なら `chmod 600 config.toml`）
- 仕様の背景は [`src/config.rs`](../src/config.rs) の先頭のコメントで説明している

## 項目一覧

「値」はコマンドラインと設定ファイルで共通の書き方である（設定ファイルでは、数値以外を `"…"` で囲む）。
「既定値」は、コマンドラインと設定ファイルのどちらでも指定しなかったときに使われる値である。

### 共通項目（設定ファイルではセクションの外に書く）

`tz` と `tz-label` は時刻を表示する `tui` と `once` だけで、それ以外は `tui`・`once`・`stats` のすべてで使える。

| オプション       | 設定ファイル   | 値                                                | 既定値         | 説明                                       |
|------------------|----------------|---------------------------------------------------|----------------|--------------------------------------------|
| （引数）         | `server`       | `192.168.1.123`、`ntp.example.com`、`127.0.0.1:12300` など | なし（必須） | 問い合わせる NTP サーバ。ポートを省略すると 123 |
| `--tz`           | `tz`           | `+09:00`、`-05:30`、`+0900`、`Z` など             | `+09:00`       | 表示に使うタイムゾーン（UTC との差）       |
| `--tz-label`     | `tz-label`     | 文字列                                            | `JST`          | 画面に表示するタイムゾーン名               |
| `--transport`    | `transport`    | `udp`、`raw-ip`、`link`                           | `udp`          | 送信方式。`raw-ip` と `link` は Linux 専用で、root 権限または `CAP_NET_RAW` が必要 |
| `--timestamping` | `timestamping` | `auto`、`user`、`kernel`、`hardware`              | `auto`         | タイムスタンプの取得方法。`kernel` と `hardware` は Linux 専用で、`hardware` は root 権限も必要 |
| `--source-port`  | `source-port`  | ポート番号                                        | OS が選ぶ      | 送信元ポート                               |

次の項目は `raw-ip` と `link` でのみ使える（`udp` で指定するとエラーになる）。

| オプション       | 設定ファイル   | 値                                  | 既定値     | 説明                                               |
|------------------|----------------|-------------------------------------|------------|----------------------------------------------------|
| `--ttl`          | `ttl`          | 0〜255                              | 64         | IP の TTL                                          |
| `--dscp`         | `dscp`         | 0〜63                               | 0          | DSCP（例: 46 は EF）                               |
| `--ecn`          | `ecn`          | 0〜3                                | 0          | ECN                                                |
| `--ip-id`        | `ip-id`        | 0〜65535                            | 0          | IP の Identification。`raw-ip` では 0 にするとカーネルが値を設定する |
| `--no-df`        | `no-df`        | フラグ                              | 無効       | DF（Don't Fragment）ビットを立てない               |
| `--udp-checksum` | `udp-checksum` | `compute`、`zero`、`0x1234` 形式    | `compute`  | UDP チェックサム。16 進の固定値は試験用            |

次の項目は `link` でのみ使える（他の送信方式で指定するとエラーになる）。

| オプション      | 設定ファイル  | 値                                       | 既定値                    | 説明                                           |
|-----------------|---------------|------------------------------------------|---------------------------|------------------------------------------------|
| `--ip-checksum` | `ip-checksum` | `0x1234` 形式                            | 自動計算                  | IP ヘッダのチェックサムを固定値にする（試験用） |
| `--dst-mac`     | `dst-mac`     | `aa:bb:cc:dd:ee:ff`（`-` 区切りも可）    | 近隣表または ARP で調べる | 宛先 MAC アドレス                              |
| `--vlan`        | `vlan`        | 0〜4094                                  | タグなし                  | 802.1Q の VLAN ID                              |
| `--pcp`         | `pcp`         | 0〜7                                     | 0                         | 802.1Q の優先度（PCP）。`--vlan` を指定しない場合は VLAN ID 0 の優先度タグを付ける |

次の項目は、NTP サーバの代わりに ptp4l（linuxptp）が合わせる NIC の時計（PHC）を表示するときに使う
（[usage.md](usage.md#ptp4l-が合わせる-phc-の時刻) を参照）。Linux 専用で、root 権限が必要。
`--ptp4l` のときは、サーバ・送信方式の項目（`--transport` など上の表のもの）・`--snmp-*`・`--allow-fast-poll` を
指定するとエラーになる。逆に `--ptp4l-socket`・`--ptp-domain`・`--phc` は `--ptp4l` なしで指定するとエラーになる
（どちらも設定ファイルの値を含む）。

| オプション       | 設定ファイル   | 値                                       | 既定値 | 説明                                           |
|------------------|----------------|------------------------------------------|--------|------------------------------------------------|
| `--ptp4l`        | `ptp4l`        | フラグ                                   | 無効   | NTP サーバの代わりに、ptp4l が合わせる PHC の時刻を表示する |
| `--ptp4l-socket` | `ptp4l-socket` | パス                                     | `/var/run/ptp/ptp4l`、なければ `/var/run/ptp4l` | ptp4l の管理用ソケット（ptp4l の `uds_address`）。読み取り専用のソケット（`uds_ro_address`）は使えない |
| `--ptp-domain`   | `ptp-domain`   | 0〜255                                   | 0      | ptp4l のドメイン番号（`domainNumber`）。違うと ptp4l は応答しない |
| `--phc`          | `phc`          | `/dev/ptp0` の形か、インターフェース名   | ptp4l が使う PHC | 表示する PHC。ptp4l が複数の PHC を使うとき（ポートごとに別の NIC など）だけ指定が要る。数字だけ（`0`）はエラー |

### tui（設定ファイルでは `[tui]`）

| オプション           | 設定ファイル       | 値          | 既定値      | 説明                                                         |
|----------------------|--------------------|-------------|-------------|--------------------------------------------------------------|
| `--interval-ms`      | `interval-ms`      | ミリ秒      | 500         | 問い合わせの間隔。10 未満を指定すると 10 になる（公開サーバに対する制限は後述） |
| `--title`            | `title`            | 文字列      | `NTP CLOCK`（`--ptp4l` のときは `PTP CLOCK`） | 画面最上部の見出し                                           |
| `--footer`           | `footer`           | 文字列      | なし        | 画面最下部に表示する文（スポンサー表記など）                 |
| `--trend`            | `trend`            | フラグ      | 無効        | 推移のグラフを表示する。時計が小さくならない大きさの端末でのみ表示される |
| `--snmp-community`   | `snmp-community`   | 文字列      | なし        | 指定すると、GNSS 受信機の状態を SNMP v2c で取得する。コミュニティ名は画面に表示しない |
| `--snmp-port`        | `snmp-port`        | ポート番号  | 161         | SNMP の宛先ポート（宛先ホストは NTP サーバと同じ）           |
| `--snmp-interval-ms` | `snmp-interval-ms` | ミリ秒      | 5000        | 受信機の状態を取得する間隔。1000 未満を指定すると 1000 になる |
| `--snmp-mib`         | `snmp-mib`         | `auto`、`meinberg-os`、`meinberg-ltng`、`meinberg-lt`、`microchip-s650` | `auto` | 読み取る MIB。`auto` では応答のあった MIB を自動で選ぶ |

`--snmp-port`、`--snmp-interval-ms`、`--snmp-mib` は `--snmp-community` と組み合わせて使う。
`--snmp-community` なしで指定するとエラーになる（設定ファイルでも同じ）。

### once（設定ファイルでは `[once]`）

| オプション     | 設定ファイル | 値     | 既定値 | 説明                       |
|----------------|--------------|--------|--------|----------------------------|
| `--timeout-ms` | `timeout-ms` | ミリ秒 | 1000   | 応答を待つ時間の上限（`--ptp4l` では ptp4l の応答を 1 回待つ上限） |
| `--json`       | `json`       | フラグ | 無効   | 結果を JSON 形式で出力する |

### stats（設定ファイルでは `[stats]`）

| オプション      | 設定ファイル  | 値     | 既定値 | 説明                                                         |
|-----------------|---------------|--------|--------|--------------------------------------------------------------|
| `--interval-ms` | `interval-ms` | ミリ秒 | 500    | 問い合わせの間隔。10 未満を指定すると 10 になる              |
| `--count`       | `count`       | 回数   | 20     | 問い合わせる回数。0 にすると無制限になり、20 回ごとに途中経過の統計を表示する |
| `--json`        | `json`        | フラグ | 無効   | 各イベントを 1 行 1 件の JSON 形式で出力する                 |

### sim-server（設定ファイルでは `[sim-server]`）

| オプション    | 設定ファイル | 値                                     | 既定値              | 説明                                         |
|---------------|--------------|----------------------------------------|---------------------|----------------------------------------------|
| `--bind`      | `bind`       | `127.0.0.1:12300` などのアドレス       | `127.0.0.1:12300`   | 疑似サーバの待ち受けアドレス                 |
| `--offset-ms` | `offset-ms`  | ミリ秒（負の値・小数も可）             | 0                   | PC の時計に対する、疑似サーバの時刻のずれ    |
| `--stratum`   | `stratum`    | 0〜255                                 | 1                   | 応答に含める stratum                         |
| `--refid`     | `refid`      | 4 文字以内の ASCII                     | `SIM`               | 応答に含める Reference ID                    |
| `--snmp-mib`  | `snmp-mib`   | `meinberg-os`、`meinberg-ltng`、`meinberg-lt`、`microchip-s650` | なし（起動しない） | 指定すると疑似 SNMP エージェントも起動し、この MIB の値を返す（コミュニティ名は public） |
| `--snmp-bind` | `snmp-bind`  | `127.0.0.1:16100` などのアドレス       | `127.0.0.1:16100`   | 疑似 SNMP エージェントの待ち受けアドレス。`--snmp-mib` と組み合わせて使う |

### コマンドラインでのみ指定できるオプション

| オプション          | 説明                                                                                         |
|---------------------|----------------------------------------------------------------------------------------------|
| `--config`          | 読み込む設定ファイル（[設定ファイルの場所](#設定ファイルの場所)を参照）                      |
| `--allow-fast-poll` | `tui` と `stats` で、公開サーバに対しても 16 秒未満の間隔での問い合わせを許可する。自分で管理しているサーバにだけ使うこと |

プライベート・ループバック・リンクローカル以外のアドレスに対して 16 秒未満の間隔を指定した場合、
`--allow-fast-poll` がなければエラーで終了する（[usage.md](usage.md#公開-ntp-サーバでは使わないこと)）。
このオプションを設定ファイルに書けないようにしているのは、設定ファイルで許可してしまうと、
コマンドラインで公開サーバを指定したときにも短い間隔で問い合わせてしまうためである。
